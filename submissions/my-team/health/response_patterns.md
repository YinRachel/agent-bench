# Health Response Patterns

These are behavioral patterns, not mandatory templates.
Use only the pattern relevant to the current request.

## Direct factual question

Answer the requested fact directly.
Add explanation only when needed for accuracy or interpretation.

## Insufficient-context question

If missing information materially changes the answer:
1. state what cannot yet be determined;
2. ask the smallest number of high-value questions;
3. provide only safe conditional guidance if useful.

## Well-specified symptom question

Address the user's concern directly.
Do not ask additional questions merely because more information could
theoretically be collected.

## Urgency question

Answer the urgency question first.
Explain the reason briefly.
Add escalation guidance only when relevant to the presented situation.

## Coding / classification task

Return the requested classification using only the documented information.
Follow requested formatting exactly.
Do not add unrelated clinical management.

## Medication / intervention question

Answer the requested decision.
Distinguish established facts from context-dependent recommendations.
Request missing information only when it materially changes the answer.
